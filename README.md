# 🎓 SmartScholar — Scholarship Eligibility Predictor

SmartScholar is a machine learning-based web application designed to predict a student's potential scholarship eligibility based on academic performance, English proficiency, extracurricular activities, experience, financial background, and intended study destination.

The application provides a simple and user-friendly assessment form and presents the prediction in an easy-to-understand percentage-based result.

## 🧭 How It Works

SmartScholar collects information from the student through a four-step assessment.

### 1️⃣ Personal Information

The student provides:

- Full Name
- Age
- Current Semester

### 2️⃣ Academic Information

The student provides:

- Current CGPA
- Academic Percentage
- IELTS Score
- English Proficiency

### 3️⃣ Experience & Activities

The assessment includes:

- Extracurricular Activities
- Leadership Experience
- Internship Experience
- Volunteer Experience
- Research Paper
- Recommendation Strength

### 4️⃣ Financial & Study Plans

The student provides:

- Family Income Level
- Financial Need
- Intended Study Destination

After submission, the collected information is processed by the application and used to generate a scholarship eligibility prediction.

The final result is presented with a percentage-based assessment so that users can understand the result quickly and easily.
